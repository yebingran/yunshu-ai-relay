# 上游来源与开源说明

云枢 AI（Yunshu AI Relay）基于 [QuantumNous/new-api](https://github.com/QuantumNous/new-api) 进行定制开发。原项目由 QuantumNous 及其贡献者维护，并源自 [One API](https://github.com/songquanpeng/one-api)。

本定制版保留网关与管理能力，加入云速管首页、独立镜像发布、1Panel 部署配置和定制项目文档；移除公开首页的官方版本更新入口。定制内容不代表上游官方发布或背书。

- 上游源码与更新：https://github.com/QuantumNous/new-api
- 上游技术文档：https://docs.newapi.ai/
- 完整 Git 历史保留上游作者、提交与原始文档，可通过历史查看。
- 本项目的部署与镜像请以 [README.md](./README.md) 为准。
